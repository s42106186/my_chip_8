# CHIP-8

Простой эмулятор [CHIP-8](https://en.wikipedia.org/wiki/CHIP-8) на языке C с графикой и звуком на базе SDL3.

## Возможности

- Эмуляция всех стандартных инструкций CHIP-8
- Экран 64×32, масштабируется до окна 640×320
- Звуковой сигнал (440 Гц) при ненулевом звуковом таймере
- Таймеры работают на частоте около 60 Гц, процессор выполняет около 600 инструкций в секунду
- Поведение оригинального COSMAC VIP: ожидание вертикальной развёртки при выводе спрайтов, сброс `VF` в логических операциях, сдвиги через `Vy`, инкремент `I` в `Fx55`/`Fx65`

## Требования

- Компилятор `gcc`
- `make`
- Библиотека [SDL3](https://libsdl.org/) (с заголовками для разработки)

## Сборка

```sh
make
```

Очистка собранных файлов:

```sh
make clean
```

## Запуск

```sh
./chip8 <имя_игры>
```

Эмулятор загружает файл `../roms/<имя_игры>.ch8` (путь указывается относительно текущей директории). Например:

```sh
./chip8 pong
```

откроет `../roms/pong.ch8`.

## Управление

Клавиатура CHIP-8 отображается на левую часть клавиатуры компьютера:

| CHIP-8 | | | | | Клавиатура | | | |
|:------:|:-:|:-:|:-:|-|:-:|:-:|:-:|:-:|
| 1 | 2 | 3 | C | → | 1 | 2 | 3 | 4 |
| 4 | 5 | 6 | D | → | Q | W | E | R |
| 7 | 8 | 9 | E | → | A | S | D | F |
| A | 0 | B | F | → | Z | X | C | V |

Выход: `Esc` или закрытие окна.

## Структура проекта

| Файл | Назначение |
|------|------------|
| `chip8.h` | Структура процессора и публичный интерфейс эмулятора |
| `chip8.c` | Ядро: инициализация, загрузка шрифтов и ROM, выполнение инструкций |
| `run.c` | Платформенный слой на SDL3: окно, ввод, звук, тактирование |
| `Makefile` | Сборка проекта |

## Ограничения

- Поддерживается только стандартный CHIP-8 (без расширений SCHIP и XO-CHIP)
- Режимы совместимости (quirks) не переключаются, используется поведение оригинального COSMAC VIP, поэтому некоторые игры, написанные для других интерпретаторов, могут работать неточно
